## 当前可运行范围

视频/声音/图片素材探测与本地导入，多轨片段、精确分割、裁切、移动、恒速、轨道锁定/隐藏/静音，画面变换、透明度、音量和文字；修订号事务、撤销/重做、原子自动保存、工程文件下载/重开；同一渲染图驱动低清预览与H.264/AAC导出，支持任务取消与HTTP206。

剪映草稿当前只读导入已验证的video结构。未知关键帧和效果保留原始副本、给出诊断，并阻止无提示导出；尚未支持其他草稿轨道类型。完整效果、曲线变速、GPU实时预览、云端能力及精细视觉对照仍在后续范围。

## 本地运行

要求Node 24+、macOS以及可用的FFmpeg/FFprobe；本机已验证默认路径 `/opt/homebrew/bin/ffmpeg` 和 `/opt/homebrew/bin/ffprobe`，也可通过 `YINGXU_FFMPEG` / `YINGXU_FFPROBE` 配置。

```sh
npm ci
npm test
npm run replay
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:8815`。开发调试时另开终端运行 `npm run dev`，入口为8816。数据独立保存在本仓库`.local/`，不会读取或改写映序数据库。上传的单个文件上限512MB；磁盘会话保留最近100个撤销/重做快照。

```sh
npm run build:desktop
npm run desktop
npm run package:mac
```

最后一条命令生成独立macOS开发包，路径记录在 `artifacts/desktop/latest.json`。当前本地包依赖上述FFmpeg，不是已经公证和完整分发验证的安装程序。桌面运行数据默认位于应用自己的userData目录，可用 `YINGXU_EDITOR_DATA` 指定。

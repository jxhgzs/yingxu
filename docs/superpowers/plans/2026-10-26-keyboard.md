# Keyboard Shortcuts Implementation Plan

> **For agentic workers:** Inline execution; this bounded fix needs no delegation.

**Goal:** 空格在GPU实时预览及片段/按钮焦点下可靠播放暂停，并统一常用快捷键。

**Architecture:** 根容器capture键盘分派；Preview提供共享transport就绪状态，controller统一toggle/step；独立shortcuts模块负责匹配、输入保护、编辑可用性与帮助表。

**Tech Stack:** Vue3/TypeScript/Electron/Node24。

**Spec:** docs/plans/2026-10-26-keyboard-design.md

## Global Constraints

- 保留用户工程、生产素材、宿主和有理数fps；不使用window全局监听。
- 输入/IME/弹窗/菜单不触发剪辑，编辑必须遵守busy/readOnly/locked与历史可用性。
- 真实UI与专项/全量/9基线/构建分别验收，不宣称全部剪映绑定一致。

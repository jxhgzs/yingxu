# Timeline Tools Implementation Plan

> **For agentic workers:** Inline execution; no delegation. User authorized implementation of the audited ten actions.

**Goal:** 将核对出的10项时间线工具接到实际命令、媒体作业及预览导出。

**Architecture:** 不可变有理数工程命令；持久派生素材作业；共享源图像裁剪窗口；Vue工具栏和弹窗调用统一controller。

**Tech Stack:** Node24、Vue3、Ant Design Vue、Electron、FFmpeg、WebGL2。

**Spec:** docs/plans/2026-10-26-toolbar-design.md；docs/qa/2026-10-26-toolbar-audit.md。

## Global Constraints

- 固定剪映5.9.0，原实验草稿先备份退出后恢复；不改生产映序、媒体或用户当前工程。
- 不复制私有实现；时间用有理数，预览/导出同源；所有修改可撤销和保存。
- GPU32图/128MiB预算不变；倒放分块，作业可取消，不允许迟到任务覆盖新修订。
- 本轮默认定格3秒、旋转90度等未取得原生样本的行为标明产品策略；真实功能通过不等于全部1:1。

### Task 1: Core timeline and crop semantics

Files: 新packages/core/src/timeline-tools.ts、crop.ts、test/timeline-tools.test.ts；改document.ts、commands.ts、edits.ts、media/render.ts、preview/plan.ts和webgl.ts。

- [ ] 对照样本先测：3秒段在1秒左裁得到源[1,3)/目标[0,2)，右裁得到源[0,1)/目标[0,1)，同轨后续前移、其他轨不变；磁吸关闭保留位置。通过createQuickCutCommand(doc,id,at,side)构造一次batch。
- [ ] 扩展Marker、Crop、clip.replace与marker命令； validateDocument拒绝非有限/越界坐标、非法颜色/时间/重复ID。split与trim保留源时钟标记，历史往返保持。
- [ ] cropPixels(asset,crop)统一整数窗口；离线crop放在色彩/暗角之后、scale之前，GPU源UV使用相同窗口、fit使用裁后尺寸。回归无crop不改变旧像素。

### Task 2: Persistent freeze/reverse jobs

Files: 新apps/service/clip-media.ts、packages/media/src/clip-media.ts、test/clip-media.test.ts；改jobs.ts、server.ts与API类型。

- [ ] 固定编号和音轨样本：冻结选中第N帧，PNG像素一致；reverse多块输入帧序和有声样本方向正确，边界无重复缺失，预算按源帧尺寸确定。
- [ ] freeze/reverse验证注册素材/轨道/范围及修订；源文件哈希复核，输出进入本地媒体库，以media-job-ID一次事务替换/插入；相同requestId只返回原job。
- [ ] 覆盖取消/失败/修订冲突与应用后重启：无部分工程修改、无重复插入。job记录保存生成asset/result及应用回执；UI只显示安全的实际状态。

### Task 3: UI integration and desktop delivery

Files: 新TimelineTools.vue、CropDialog.vue、MarkerDialog.vue；改Timeline.vue、Icon.vue、controller.ts、App.vue、shortcuts.ts、style.css、版本及QA。

- [ ] 实际独立UI逐项验证，输入和模态不误触发Space/M；媒体任务显示进度和取消；时间线滚动不破坏定位/标记。
- [ ] 全量、9基线、类型/构建；专项真实GPU像素与context恢复。运行时提交后打包0.11.0，正常退出旧App再开新包，核签名、bundle和用户当前工程哈希。
- [ ] 记录每项实现、目标证据及剩余差异，关闭临时服务和标签，保留新App打开。

# 可运行编辑与导出链路实施计划

前置：首包六快照回归已实际通过，见artifacts/core-baseline.json。沿用已确认Vue 3＋TypeScript＋Ant Design Vue设计，在当前会话实施，不改映序。

本包建设可操作的独立版本，完整复刻仍按登记册推进。本包不宣称复杂曲线/特效、云服务、GPU实时预览或全部视觉已经与剪映一致。

## 1. 扩展统一工程与编辑命令

- [x] `packages/core/src/document.ts`增加可选媒体类型、元数据、画面变换、声音增益、文本样式与轨道开关，旧六快照仍可读取，既有语义投影不变。
- [x] `packages/core/src/edits.ts`新增素材入库、添加/删除/移动/裁切片段、变换、声音、文本、轨道和画布设置。所有修改先复制、后校验；仍通过session的revision事务提交。
- [x] 测试多轨、文本、源入点裁切、锁定轨道、失败原子性和历史恢复；命令选择参数不宣称是剪映默认。

## 2. 原生媒体参照与本地服务

- [x] `packages/media/src/probe.ts`调用FFprobe取得真实帧率、尺寸、声音和时长，SHA256绑定输入。`render.ts`以独立FFmpeg子进程执行统一渲染图。
- [x] 同一图支持低清预览和正式导出，仅画幅/编码参数不同；恒速、裁切、轨道层级、画面变换、音频混合和文字都从该图生成。
- [x] `apps/service/`保存独立媒体、工程与作业；原子落盘，修订冲突拒绝；jobId绑定工程哈希和输入哈希。进程恢复标记中断，不能把未知任务当完成或自动重发。
- [x] 本地API负责上传、素材探测、工程命令、保存/打开、预览和导出。所有媒体和导出支持HTTP206/HEAD；取消只作用于目标作业。
- [x] 用六秒自制源、编号帧/双色叠轨和正弦声音检查实际导出时长、帧数、切点、像素、声音；解码和实际听审分开记账。

## 3. Vue与Ant Design Vue界面

- [x] `apps/editor/`建立完整编辑工作区：素材区、预览区、属性区、可滚动多轨时间线、播放头、导出弹窗。
- [x] UI只发送核心命令；工程使用shallowRef，播放头/选择/焦点独立。文本输入时不触发分割/删除快捷键。
- [x] 通用控件使用Ant Design Vue暗色主题；时间线和预览为专用组件。未实现的功能不做假成功按钮。

- [x] 实际UI导入、分割、改速度、撤销/重做、增加文本、保存重开及导出；检查窄窗口和全尺寸。

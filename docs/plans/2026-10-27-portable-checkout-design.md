# 独立检出启动与打包

范围：同事在 Apple 芯片 Mac 安装 Node.js 24+、FFmpeg/FFprobe、Rubber Band 后，仅凭仓库执行 npm ci、构建、运行和 package:mac，不需要作者的调研目录、剪映安装或缓存。保持现有 Vue/Electron 架构与工程格式，不触碰生产平台和正在编辑的工程。

采用仓库内独立生成的六秒测试图与正弦音演示素材；不复制原生研究样片。服务和打包共用该文件，记录来源与校验值。字体继续使用已入库的许可版本。原生对照实验仍是可选研发资料，不伪造缺失基线。

媒体工具统一按显式环境变量、PATH、macOS 常用 Homebrew 路径查找，兼容 Finder 的简化 PATH。显式错误路径不得悄悄切换到另一引擎。新增 doctor，检查工具、关键滤镜、编码器、素材和字体；打包额外检查 macOS 和 Electron。开发代理补齐文字与曲线音频资源。

替代方案：要求同事复制私人目录无法实现独立检出；捆绑完整 Homebrew 动态库树会额外引入版本、签名和许可证分发工作。本次以明确可安装的标准媒体依赖为边界，生成包仍是依赖媒体工具的临时签名开发包，不宣称公证分发完成。

验证：路径解析单元回归、环境检查缺失依赖失败分支、HTTP 演示/导出/206、文字与曲线音频、类型检查与构建；在系统临时目录独立 clone、npm ci 并打包，直接运行打包后的服务验证随包素材和字体，不借用相邻资料目录。

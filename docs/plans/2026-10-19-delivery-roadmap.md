# 完整推进路线与验收关卡

目标始终为本机剪映5.9.0完整功能对照，界面采用Vue 3＋TypeScript＋Ant Design Vue，随后嵌入映序。当前已完成若干独立编辑与导出路径；以下为完整路线，各条实际进展以功能登记册和QA为准，不能将分阶段通过当作完整验收。

## 先明确工作边界

拆成四个独立实施包，各自产出可测试的软件和证据。首包给逐步实施计划，其余包先冻结职责、输入输出与验收关卡；待前置实验形成证据，再各自编写逐步计划，避免把未经验证的行为写成算法。

整个版本的菜单和面板尚未完整枚举，因此不提供虚假的完成比例、固定工期或「几天完全复刻」承诺。功能登记册中的候选能力必须先在固定版本确认。

## 包A：工程、精确时间与编辑命令

输入：六份只读草稿快照、六秒素材、已确认的区间与速度行为。输出：独立TypeScript核心包、只读导入CLI、操作回放与自动回归报告。

执行顺序：有理数时间 → 工程及来源副本 → 只读导入与诊断 → 分割及恒速命令 → 版本化撤销重做 → 六快照对照。

验收关卡：

- 30fps样例无24fps量化；30000/1001的帧时间往返计算精确。
- 三秒分割与二倍速操作的语义投影和目标快照一致，撤销精确恢复内部工程。
- 未知效果和关键帧原文不丢失；未确认的关键帧时钟不进入渲染计算。
- 命令失败、旧修订提交和重复ID不会改变工程或历史；导入不改原文件。
- CLI能输出机器可读报告，进程码区分成功、结构拒绝和回归失败。

此包不宣称媒体结果或UI已经对齐。精细裁切、联动、曲线变速、分组等在专项对照后扩展命令。

## 包B：媒体引擎与预览/导出

输入：包A工程、已确认时间映射、固定媒体。输出：独立作业进程、渲染图、真实导出、预览接口及性能记录。

先完成三片段联动与关键帧时钟实验，再冻结变速及动画语义。初始CPU参考链路用FFmpeg；VideoToolbox/Metal是否及如何接入，通过同素材的解码、合成、帧传递与内存探针选择，不能只凭目标程序含Metal断定方案。

协议最少包含：`protocolVersion`、`jobId`、`documentRevision`、`documentHash`、`operation`、`inputHashes`。事件带jobId、阶段、已完成量/总量或不可用标记、结果/错误；取消按jobId精确作用。

依次验证：媒体探测与缺源 → 线性剪辑及音频 → 位置/缩放与图层 → 已确认关键帧 → 文字/字幕 → 转场与效果 → 实时播放时钟及缓存 → 高分辨率与异常恢复。

验收关卡：

- 六秒基础导出参数与目标一致；编号帧源检查切点、源入点与倍速无偏帧。
- 预览和导出消费同一图与时间映射；未知效果不能被静默忽略。
- 字体、色彩、音频与画面分别验收。解码成功不代替听审；设置参数不代替ffprobe实测。
- 缓存键包含输入、图、字体/效果、版本和输出参数，修改其中任一项会正确失效。
- 取消、崩溃和重开恢复不覆盖现有成片，不重复启动已持久化的任务。
- 性能与剪映在同设备、同工程下测量，记录p50/p95、掉帧、峰值内存及缓存状态。数值容差在取得目标基线后正式冻结。

## 包C：Vue编辑器与界面对照

输入：包A命令、包B预览/导出接口、逐屏UI与操作证据。输出：独立Electron编辑器和可嵌入Vue应用。

UI文件按领域分组：`workspace/`、`media-bin/`、`preview/`、`timeline/`、`inspector/`、`export/`、`host/`。Ant Design Vue用于常规控件，统一主题由编辑器入口注入；时间线、波形、曲线与画布独立绘制。

接口：`mountEditor(container, options): EditorHandle`。options提供文档、媒体解析器、保存和任务接口；handle支持 `open(document)` 和 `dispose()`。核心包不依赖Vue，宿主不读取Vue代理。具体类型在此包实施计划中与已实现内核逐项对齐。

先跑通导入→剪辑→撤销→保存重开→真实导出完整路径，再补齐菜单、属性、多选、关键帧、快捷键、错误态及完整视觉。没有内核支持的按钮不做成假成功操作。

验收关卡：

- 同窗口尺寸、显示缩放、语言和快捷键配置逐屏对照；默认Ant Design样式不作为剪映视觉完成。
- 数值输入、焦点、鼠标拖动、快捷键和上下文菜单均使用真实界面操作验证。
- 长轨道只绘制可见范围；播放头更新不触发全部素材与属性面板重绘。
- mount/dispose循环20次无残留监听器、计时器、预览作业和对象URL；销毁后迟到事件不改新会话。
- 未保存编辑、媒体缺失与导出失败均有可恢复路径。

## 包D：映序宿主与工程兼容

输入：独立编辑器、媒体进程、映序素材/节点/任务/工程接口。输出：可从映序打开与保存的编辑入口，保留旧工程的集成版本。

只在此阶段修改映序。先为React宿主添加容器生命周期适配，再接素材解析与冻结版本、编辑清单、作业映射、成果采用和Agent命令。

旧24fps时间线按源模型解释，复制转换为新工程；不通过改旧常量将所有历史数据假定为新模型。新`.yg`扩展清单必须带schema版本、输入引用、工程哈希和媒体完整性信息。新工程转换不了的字段保留并报告，不在导入时清空。

验收关卡：

- 原工程、历史成片与生产任务在新入口打开/取消/保存后仍可访问；旧入口仍能读原数据。
- 上游素材变更后，已冻结工程与运行任务使用原修订；新旧版本可明确选择。
- 老包→新编辑→另存→重开全流程通过，并核对实际媒体、音轨、HTTP206和来源关系。
- stale版本命令被拒绝；请求重试不重复创建导出任务或成果节点。
- 按生产平台AGENTS.md运行适当检查，并做真实桌面路径验证。

# 本地特效迁移适配（0.12）

沿用 Vue + 独立媒体引擎。目标为实际可预览、可编辑、可导出的新增效果，不将扫描数量当作迁移数量。本轮只读取本机完整缓存，不请求商城、登录或付费接口，不执行资源自带 Lua。

## 交付范围

1. 本地特效库入口，扫描 effect / artistEffect，区分文字动画、序列贴纸、静态贴纸、字体和未适配模型。显示可用状态、已观察的付费标记、未验证原因；未适配按钮置灰。
2. 付费文字资源 12453543「放大缩小」：独立实现两条 AE Bezier 缩放曲线与逐字原布局，保留入/出场组合、旋转及换行。原生收费导出要求登录，本轮原生 UI 点击失败，故发布为实验适配，不宣称原生像素 1:1。
3. 完整 462512 的 96 帧 / 25fps 序列转换为保留 alpha 的本地媒体；静态 singleImage 贴纸导入为本地媒体。内容哈希、原始文件哈希和适配版本持久化到独立 provenance，未知混合/脚本资源拒绝。
4. 资源应用前检查当前选择/轨道/工程状态；文字预设不清除其他阶段动画；图像/序列导入后可在素材库复用。原始缓存路径不成为可执行输入。

## 实施及验收

- [x] 核心逐字缩放、ASS/GPU 帧缓存一致，边界/奇偶/空格换行/旋转测试。
- [x] 服务固定根目录扫描、路径安全、资源变更重检、内容复制与去重、缺依赖禁用。
- [x] Vue 可搜索过滤资源库，实际点击应用及置灰验证。
- [x] 序列 alpha 解码、导出合成与重启持久化验证；不支持浏览器解码的无损序列明确回退后台预览。
- [x] 全量测试、基线回放、类型/构建检查。保留最新用户工程，完成桌面开发包验证。

资源和闭源静态分析内容只存在 ignored 本地数据/QA，不加入发布源码。字体（尤其预览子集）、脸部模型、复杂模板、HDR/迁色、未适配 shader 继续禁用，不能以近似基础效果顶替。

用户在[工具栏核对](2026-10-26-toolbar-audit.md)后授权“做上吧”。运行时提交a8b1188，采用独立Vue3/Ant Design Vue/Electron及媒体引擎；本轮未启动新REA会话，沿用已取得的5.9.0原生操作证据，不复制其实现。

## 实际行为

| 工具 | 实现与验收 |
|---|---|
| 分割 | 复用有理数分割和历史；位置/锁定/转场限制统一提示 |
| 左右快速裁切 | 一次替换及同轨移动事务，保留ID；普通主轨磁吸开启时匹配原生1秒样本；关闭时留间隙 |
| 删除 | 连接原删除命令，保持撤销和锁定守卫 |
| 标记 | 全局/片段源时钟，M添加，名称颜色、定位删除、分割过滤及持久历史 |
| 定格 | 当前源帧生成独立PNG，求值当前变换，在播放头插入约3秒静帧并移动同轨后续段；不改源文件 |
| 倒放 | 选中源区间分块生成独立视频和倒序音轨，替换素材，保留目标时长、速度及效果；可取消/撤销 |
| 镜像 | 水平翻转直接入口 |
| 旋转 | 顺时针90°；有旋转关键帧则写入当前源时刻 |
| 裁剪比例 | 自由与7种常用比例，四角缩放、拖动及数值输入；同一整数源窗口送GPU及离线导出 |

工具顺序按目标排列，复制/轨道移至后组。裁剪与时间裁切分开；没有用空按钮代替功能。

## 验证结果

- 全量359/359；9/9语义基线；类型检查和桌面构建通过。见证据中的checks.json与日志。
- 固定编号帧：冻结像素精确；多块倒放逐帧顺序无重复缺失，音频斜坡方向反转。30000/1001、量化容器时间戳、非零37帧入点跨块测试通过；VFR明确拒绝。
- 实际HTTP作业：同requestId复用任务、一次历史、撤销、旧修订冲突、应用后模拟崩溃恢复回执均通过。实际界面取消倒放后修订12及片段保持不变。
- 隔离UI工程中，左裁得到源1—3/目标0—2、后段从3移至2；撤销后右裁得到源0—1/目标0—1、后段移至1。镜像、旋转90°、裁剪框缩放/移动后得到源窗口(360,50,584,584)。
- 定格后总长6→9秒、图片1—4秒、后续片段正确前移/后移，撤销恢复。倒放完成后仍保留裁剪/镜像/旋转和标记数据；原素材保留。标记改名、输入Space/M、定位、删除及M重新添加通过。
- Apple M3真实WebGL：裁剪×镜像×90°旋转四种组合，context丢失恢复后再四种，全4096像素的8组最大误差均0；未启用持久缓冲或增加缓存预算。见gpu-pixels.json。
- 独立UI实际导出带倒放、裁剪、镜像、旋转的6秒工程，H.264 1280×720、180帧、AAC，实际解码和第1秒画面检查完成。见export-frame.png；没有把导出完成提示单独作为成功证明。
- 修复集成中发现的两处问题：GPU字段白名单漏掉crop/markers曾导致回退；busy禁用按钮和Antd退出动画恢复BODY曾丢失快捷键焦点。已加入计划回归、工具操作后根聚焦及媒体弹窗afterClose；实际取消后直接Space可播放。标记名称blur后颜色输入保持焦点。

## 适用边界

本轮3秒定格、90°旋转及关闭磁吸行为为产品策略；前轮只取得普通主轨磁吸开启的原生快速裁切样本，不能泛化为全部1:1。原生定格/倒放的像素与默认参数、多选、复杂曲线组合、完整快捷键配置仍待核准。

定格/倒放要求可验证的均匀帧时钟；VFR和不支持的显示变换明确报错。倒放最长1小时/最高120fps，分块解码窗口名义128MiB，额外编解码开销不等同该窗口预算；输出H.264/AAC会有编码损失，不声称无损。时间编辑继承转场、部分文字动画/曲线关键帧限制与100条原子命令批次上限；不支持时拒绝，不部分修改。GPU8组检查证明本轮裁剪组合及恢复，不代表所有源格式/字体/转场/长工程全部对齐。

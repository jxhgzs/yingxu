# 媒体重新链接验证

日期：2026-10-19。范围为独立内核及Vue弹窗接入代码，未取得剪映5.9.0原生重新链接操作证据，不宣称交互完全一致。

## 核心行为

`applyAssetRelink(document,{assetId,replacement})`不读取文件或访问路径，只操作文档。先核对原素材、替换素材及受影响引用，完整预检后一次克隆文档，改写全部引用并删除旧素材，再校验最终文档。

- video/image允许互换，audio仅可替换audio，text明确拒绝。
- 保留源/目标区间、速度、变换、音量和源时钟关键帧。替换素材时长不足以容纳任何源区间或动画点时拒绝，不擅自截短片段或删关键帧。
- 任何受影响轨道锁定或片段`editableTiming=false`时拒绝；不修改未知时间映射。
- 新ID已在工程中时，path、sha256、时长、类型、尺寸、声音存在状态、帧率与MIME必须一致才复用。name可作为独立工程标签保留。相同ID不能用来偷偷改媒体身份。
- 原SHA缺失或替换SHA不同均可接受，因为操作为用户明确选择的重新链接或替换；服务必须强制使用`store.assets`可信注册数据，不能接受客户端伪造路径。

## 界面

`RelinkDialog.vue`提供工程原素材、兼容注册候选和导入文件入口；并排显示名称、类型、时长、尺寸及校验值，显示全部引用数量。哈希不同或旧哈希缺失有明确提示，按钮提交一次`asset.relink`命令。预检错误、busy和只读状态禁止提交；上传不会自动保存替换。组件不将旧asset.path作为浏览器URL或文件读取路径。

App入口、命令类型、服务sanitization与实际交互/导出由主执行者完成。本组件尚未完成真实UI验收，类型检查不替代界面检查。

## 实际测试

`node --test test/relink.test.ts`：5/5通过；连同字幕测试14/14通过（Node v24.18.0）。

1. 同素材跨两画面轨、不同源入点和二倍速的全部引用一次更新；区间、变换及曲线原样保留；输入工程与替换对象没有共享修改。
2. 已存在的相同注册身份复用，path/SHA/时长冲突拒绝；相同ID一致数据为不改变内容的操作。
3. 原素材不存在、文字/音频类型不兼容、替换过短、锁定轨道及未知时间映射拒绝且原文档不变。
4. video/image兼容、audio独立、未采用素材也可更换；无需访问测试中不存在的旧路径。
5. 片段使用区间之外但仍保留在原素材时钟内的关键帧也不能被短素材吞掉，明确拒绝。

`asset.relink`命令接入后`npm run typecheck`通过，组件未使用类型断言绕过。持久化、撤销/重做、伪造路径拒绝和实际渲染仍需服务与UI集成验证。

## 跨工程异步保护

弹窗打开时绑定工程ID；切换工程后禁用选择/上传/提交，并用中文要求关闭重开，即使切回原工程也不能复用旧窗口。上传和重新链接捕获工程ID、来源素材ID与会话epoch；关闭、卸载、切换工程后忽略旧异步回调，不在新工程自动选择文件或显示旧错误。切换工程释放本地working，避免旧上传让窗口无法关闭。此项已代码复查与类型检查，真实异步UI交互仍由主任务验证。

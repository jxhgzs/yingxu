## 本次可操作的能力

### 转场

`Document.transitions`独立记录同轨相邻片段关系，新增/改类型/改时长/删除均进入原子历史，可撤销重做并保存重开。界面素材区与属性区均可进入，时间线上显示实际转场窗口。

| 类型 | 已知原生资源 | 独立实现 |
| --- | --- | --- |
| 叠化 | resource6724845717472416269 / effect322577 / overlap=true | 剪辑点±D/2，从各自源时钟延伸handles；隔离的预乘RGBA线性混合后覆盖下层 |
| 闪黑 | resource6724239388189921806 / effect321493 / overlap=false | 两侧各自原采用区间，不读额外handles；前半退到不透明黑，后半从黑进入 |

工程总时长保持不变；音频仍按原切点衔接，本次没有原生声音转场证据。未知资源/属性保留来源与诊断，不能静默替换成叠化。源余量不足直接拒绝。

当前产品边界：仅恒速视频；时长至少一帧、最多任一侧片段时长的一半；关联片段的时间编辑需要先移除转场。两侧时长上限、一帧下限及拒绝余量不足是本产品保守边界，尚未证明与原生全部边界行为一致。图片、曲线、其他转场和复杂叠加继续待补。

### 基础调节

开放亮度、饱和度、高光、阴影四项，UI−50…50对应原生value−1…1。导入只接受已核验的combine_adjust结构及代际：brightness v2、saturation v1、highlight/shadow v3。四项顺序固定为亮度→饱和度→高光→阴影，各阶段clamp；共享纯函数生成CPU参数、GPU uniform和独立FFmpeg查表。

导出使用自行计算的65536点1D浮点LUT与饱和矩阵，避免逐像素解释geq。alpha保留；LUT文件按参数哈希命名、大小/SHA检查、原子发布，内存与每作业磁盘数量均受限。当前每作业最多64张LUT，超出明确报错，不能称无限规模支持。旧geq保留为数学参考，不再用于正式效果渲染。

数值输入通过“应用调节”或回车一次提交组合，滑块松手提交；修复了失焦逐字段提交导致异步修订覆盖下一个输入的问题。重置、组合的一次撤销/重做及重开均经真实界面验证。

## 色彩精度与误差

输入保留已支持的matrix/transfer/primaries/range标签；缺标签采用有标记的SD/HD启发式。仅640×360→SMPTE170M和1280×720→BT709有本次浏览器/原生证据，`width>=1280 || height>576`阈值是产品策略，未证明为原生规则。HDR、广色域和未支持标签拒绝导出/转备用，不能假作SDR。

有活动调节的视频用zscale直接转gbrapf32le，输入输出transfer/primaries相同，运算保持编码域。原先swscale→RGBA的白点Y235仅到约0.99615，近白逆曲线将误差放大；zscale浮点约0.99999994。不能把问题仅归结为最终编码，亦未使用截图gamma补偿。

完整实际导出链（含合成、H.264编码后再统一FFmpeg RGB解码）与九组原生18色块中心对照：**灰阶最大2、彩色最大4个8bit码值**。零调节灰阶完全相等、彩色最大2。容差针对这组SDR fixture冻结，不代表所有像素、参数、叠加、格式或HDR一致。测试`color-effects-native-render.test.ts`直接覆盖正式render入口；源4.8KB视频为自有生成素材，原生MOV仅在本地证据中保存。

LUT与CPU方程另用11×8192个浮点像素验证：最大约0.042519 LSB，alpha位模式不变。这个数不是原生/最终编码误差。

浏览器HTMLVideoElement由Chromium选择解码矩阵，WebGL使用sRGB RGBA8纹理和编码域混合；不能由工程标签强制改变浏览器内部解码。GPU raw readPixels、源Canvas2D采样、最终编码RGB和截图显示分别记录，不互相冒充。原生叠化中点编码RGB为[126,18,127]，GPU未编码buffer为[128,20,128]，不能宣称像素完全相同。

## GPU预览

实际路径：HTML媒体解码→WebGL2纹理/变换/基础调节/转场合成；WebAudio单独控制音量、源时钟关键帧和目标时钟qsin淡变。支持工程修改后无需整片后台重渲染；用户可切换后台预览。缓存键加入实际媒体代码、核心代码、字体与打包后bundle哈希，旧引擎预览不能冒充当前结果。

当前支持恒速视频、图片、音频、多层静态变换、已支持线性/保持属性关键帧、四项调节及两种转场。可见文字、曲线及未知效果自动转后台，有明确原因。解码器上限12并发、缓存24；GPU缓冲最大边1280，软件renderer标为WebGL实时，不能标为硬件GPU。

实际设备：Apple M3，ANGLE Metal Renderer，WebGL2。真实UI四秒叠化+四项组合调节完整播放记录：

| 观测 | 数值 |
| --- | --- |
| 输出跳帧 / 解码器掉帧 | 0 / 3 |
| 平均合成CPU时间 / 最后一次GPU计时 | 1.61ms / 0.413ms |
| 最大观测源时钟偏差 | 43.28ms |
| 转场FBO | 2个、7372800字节、只分配一次对 |

这是短小工程本机观测，没有同工程原生剪映性能基线；未作实际听审。displayedFrames包括定位/末帧，不能据此宣称零解码掉帧或全链路30fps保证。

真实UI还验证：闪黑中点readPixels=[0,0,0,255]；非对称上下色块在转场两侧FBO与最终画布一致，没有垂直翻转；修改/删除/一次撤销/重做/重开；自动实时与后台切换生成当前引擎作业。

实际20次mount/dispose：DOM残留0、迟到变化0、销毁后请求0，销毁后open拒绝20次，无WebGL上下文数量警告。真实WEBGL_lose_context测试最初暴露恢复后1282错误：删除失效旧句柄污染了新上传检查；现丢失时丢弃失效句柄，恢复重建并定位，前后像素一致，保持暂停。已补外部失效语义回归，未通过自动播放掩盖恢复。
